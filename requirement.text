# FinTrack — Complete Description

## Kya hai ye app?

**FinTrack** ek fully-functional, production-quality **Personal Finance & Expense Management Dashboard** hai jo maine React + Vite se banaya hai. Ye completely **frontend-only** hai — koi backend, database, ya server nahi hai. Sara data user ke browser mein **localStorage** mein store hota hai, lekin architecture aisi hai jaise ye ek real SaaS app ho (services layer, REST-jaisa structure) — taake future mein asaani se real backend connect kiya ja sake.

## Core Features

- **Authentication** — Register/Login/Forgot Password (mock, but real validation + hashed passwords)
- **Dashboard** — Balance, Income, Expenses, Savings Rate — sab dynamically calculate hoti hain, koi fake numbers nahi
- **Transactions** — Add/edit/delete income & expense, search, filters (type/category/date/amount), sorting, pagination, receipt upload
- **Budgets** — Category-wise monthly budget, automatic usage tracking, 50%/80%/100% alerts
- **Goals** — Laptop, car, travel, emergency fund jaise goals banao, progress track karo, paisay add karo
- **Subscriptions** — Netflix, Spotify jaisi recurring subscriptions track karo, monthly cost auto-calculate ho
- **Analytics** — Pie chart (category-wise expense), bar chart (monthly expense), line chart (income vs expense vs savings)
- **CSV Export** — Transactions ko CSV mein export kar sakte ho
- **Notifications** — Budget warnings, upcoming subscriptions, goal milestones
- **Dark/Light Mode** + **Multi-currency** (PKR, USD, EUR, GBP, AED, SAR)
- **Fully Responsive** — Mobile pe sidebar drawer ban jata hai, tables cards mein convert ho jate hain

# Working Flow (User Journey)

1. **Register** → Naya account banao (name, email, password)
2. **Login** → Dashboard pe redirect ho jata ho
3. **"Load Demo Data"** button click karo (agar test karna ho quickly) ya khud income/expense add karo via **Quick Actions**
4. **Add Income/Expense** → Form khulta hai (title, amount, category, date, payment method) → Save karte hi Dashboard automatically update ho jata hai
5. **Transactions Page** → Search karo, filter lagao (type/category/date), sort karo, edit/delete karo
6. **Budgets** → Kisi category (jaise "Food") ke liye monthly limit set karo → Jaise-jaise expense add hoti hain, progress bar aur % automatically update hota hai
7. **Goals** → Naya goal banao (target amount + deadline) → "Add Money" se progress badhao
8. **Subscriptions** → Recurring payments add karo → Monthly estimated cost automatically calculate ho jaye
9. **Analytics** → Charts dekho jo real transaction data se dynamically banti hain
10. **Settings** → Theme change karo, currency change karo, password change karo
11. **Refresh browser** → Sara data persist rehta hai (localStorage ki wajah se)
12. **Logout/Login** → Same user ka data wapis aa jata hai
13. **Doosra user register** karo → Pehle user ka data bilkul nahi dikhega (user isolation)

Har button real kaam karta hai — koi fake/dead button nahi hai.
